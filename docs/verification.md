# Verification and support status

The terminal-review refactor removed the review website and mutation server. The current viewer work adds a separate read-only Kumo browser reader and loopback server, without restoring web approval. It retains a guarded human terminal review transport while preserving Core validation, immutable history, host hooks, WebFetch offset and bounded native question/discovery handling. Version 0.1.0-rc.5 is being published as an explicitly authorized prerelease with the human/native stages below still incomplete.

Prior evidence before this refactor: 145/145 product cases, 11 repeated UI policy cases and 272 public payload files passed. Those are historical counts, not the current protected-terminal and read-only-viewer suites or native acceptance. The removed web-only cases are not relabeled as passing replacements. Current runs must report their actual case/file counts, commands, failures and omissions.

Required automated checks: deterministic build, lint, TypeScript, Core/path/schema/ownership/recovery tests, terminal judgments/denial/scope/pause-resume, transport guard and agent entry denial, both relocated consumer payloads, archive checksums and a scan for removed Studio/review HTTP entrypoints, an exact read-only asset allowlist, viewer no-write/path/origin/method checks and local-only bundled assets.

Required native checks remain distinct for Claude Code and Codex; see [native host verification](native-host-verification.md). Synthetic human I/O/service calls, ordinary CLI checks, process-boundary fixtures and regenerated hooks do not prove actual native tools or a human-operated TTY. Preserve failures and report blocked/not-run stages accurately.

The rc.5 release assets include VERIFICATION.md with the exact commit, CI, artifact hashes and executed commands. See [rc.5 release notes](releases/v0.1.0-rc.5.md).
